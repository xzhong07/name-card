# Name Card App (Flask)

Flaskをバックエンドとして用いた名刺Webアプリケーションです。  

## デモ

以下のURLから実際の動作を確認できます。
https://name-card-7czn.onrender.com

## 概要

フロントエンドはHTML/CSSで構築され、バックエンドはPythonのFlaskフレームワークで実装されています。

## 使用技術

- Flask
- Python
- HTML / CSS

## 学習目的

- FlaskによるWebアプリケーションの基本構造の理解
- バックエンドとフロントエンドの連携方法の理解
- シンプルなWebサービスのデプロイ経験（Render等）
